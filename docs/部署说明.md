# 部署说明（单机及局域网）

**环境**：JDK 17/21、Maven 3.9、MySQL 8.0.16 及以上、现代浏览器。示例数据库可用 Docker Compose 创建。服务器与访问设备须连接同一局域网。

1. 解压源码，进入项目根目录。运行 `docker compose up -d`，用 `docker compose ps` 确认 MySQL healthy。首次初始化执行 `sql/assignment2-original.sql`。也可在本机 MySQL 的新库中手工执行该脚本。
2. 执行 `mvn clean package`，之后设置 `DB_URL=jdbc:mysql://127.0.0.1:3307/dorm_management?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`、`DB_USER=dorm_app`、`DB_PASSWORD=dorm_app_demo`，运行 `java -jar target/dorm-management-1.0.0.jar`。Windows PowerShell 的完整命令见 README。
3. 本机打开 `http://localhost:8080`。在服务器上用 Windows `ipconfig` 或 Linux `ip addr` 查看局域网 IPv4；教师电脑访问 `http://服务器局域网IP:8080`。若不能访问，检查双方是否处于同一网络、学校网络是否隔离设备、系统防火墙是否允许 TCP 8080，以及端口是否被占用。MySQL 仅监听服务器本机 3307，不需向局域网开放。
4. 演示账号：`admin` / `123456`、`student01` / `123456`。修改默认密码，并在实际演示设备上记录真实访问地址和截图。
