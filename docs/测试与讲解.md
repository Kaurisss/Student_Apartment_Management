# 测试与讲解提纲

## 实际验证记录

- 原设计 SQL：在 MySQL 8.0.46 新库执行，创建 6 张表并载入 2 个账号、1 个学生、1 个宿舍、2 个床位、1 条待受理报修、1 条已分配入住记录。两个初始密码的 PBKDF2 哈希均与 `123456` 匹配。
- JSON 接口自动测试覆盖账号/学生/宿舍/床位和报修维护、分页、登录、CSRF、角色隔离、两条闭环、跨用户越权、重复申请、占用床位冲突、退宿释放和统计数值。`scripts/smoke_test.py` 会写入测试数据，须用于专用测试库。Vue/Ant Design Vue 页面通过 Chromium 实际操作报修、入住、退宿及表单校验，并在 `docs/运行截图` 留存测试过程。实际课堂局域网需另行验证。

## 建议的答辩讲解顺序

前端入口为 `frontend/src/App.vue`：页面用 Ant Design Vue 的布局、表格、表单、菜单及弹窗，通过 fetch 调用 `/api`，把 CSRF 令牌放入请求头；导航和新增操作使用 `@phosphor-icons/vue`。前端校验用于提示，权限、状态和数据约束在 Java 后端再次检查。

1. **登录和权限**：`SecurityConfig` 从 user 表取用户名、哈希、角色，PBKDF2 按存储格式解析迭代次数、盐和哈希；Spring Security 检查密码、管理会话和 CSRF；`/admin/**` 仅管理员，业务操作再次判断角色和所属学生。
2. **普通数据维护**：`AdminService.entity` 用白名单定义四类实体与字段，输入经必填、长度、选项校验，SQL 参数化；分页计算总页数并用 LIMIT/OFFSET；唯一键和外键处理重复及关联删除。报修单在待受理时也可增删改查。
3. **报修**：`repairAction` 先锁行，再按 `WAITING → IN_PROGRESS → COMPLETED → CONFIRMED` 检查当前状态及角色；评价由本人填写。处理中或之后不可随意修改、删除。
4. **入住**：`createHousing` 锁学生并检查未结束记录；`assign` 锁入住记录、学生和床位，验证空闲后，在同一事务中设床位 OCCUPIED 和入住 ASSIGNED；数据库生成列的唯一索引阻止一个床位或学生有多条有效分配。`checkin` 办理入住；学生请求退宿只记录时间；`checkout` 同一事务更新入住记录并释放床位，异常时整体回滚。数据库记录保留历史床位。
5. **统计**：已占用床位 / 全部床位；COMPLETED + CONFIRMED 报修 / 全部报修。分母为零显示 0.0%。
6. **测试**：演示正常流程，再尝试跳状态、越权、重复申请或占用已分配床位；查看失败反馈、床位状态与统计数值。说明真实课堂局域网如何验证。

约束边界：住房表原设计没有在数据库层强制“每名学生最多一个 PENDING”；应用通过事务内学生行锁保证经本系统提交的并发申请。请勿绕开应用直接修改床位状态。示例脚本为初始数据，非迁移脚本。

## 复测方式

`scripts/smoke_test.py` 是有写入操作的接口测试，必须使用只供测试的全新数据库。以下为 Linux/macOS 的一种方式（需自行输入 MySQL 密码）：

```bash
# 确认测试库名称不存在；只替换脚本中的库名并导入新库
sed 's/dorm_management/dorm_management_test/g' sql/assignment2-original.sql | mysql --default-character-set=utf8mb4 -u root -p
# 为测试专用 MySQL 账号授权访问 dorm_management_test，再用该账号启动单独的应用实例
DB_URL='jdbc:mysql://127.0.0.1:3306/dorm_management_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai' \
DB_USER=测试账号 DB_PASSWORD=测试密码 SERVER_PORT=18080 java -jar target/dorm-management-1.0.0.jar
# 另开终端运行
BASE_URL=http://127.0.0.1:18080 python3 scripts/smoke_test.py
```

若使用本项目 Compose 数据库，端口为 3307，需根据实际环境给测试账号授权。重复运行前请使用新的测试库并重新导入原始数据；测试会新增、修改和删除记录，不应指向课堂或个人正式数据。
